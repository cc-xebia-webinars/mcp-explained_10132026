# Onboarding Notes for New Engineers

Welcome to the Storefront team. These notes cover the first week.

## Accounts

- Ask your manager to add you to the GitHub organization and the `storefront` team.
- Request access to the Azure subscription through the internal access portal.

## Your first week

- Read the release checklist in this folder before your first on-call shift.
- Pair with the current on-call engineer for at least one release.
- Pick up an issue labeled `good first issue` in the storefront repository.

## Who to ask

- Release questions go to `#storefront`.
- Platform and access questions go to `#platform-ops`.
